## いまのプロジェクトの立ち位置（だいじ）

- 現在は **叩き台（プロトタイプ）から作り直し中**。技術は **TypeScript + Phaser 3 + Vite** のまま維持。
- **いま実際に動く「新方向」＝ 歩行サンドボックス**（画面 **1280×720**）。
  歩く・壁を置く・イベントを置く・自作素材を差し込む、を試せる土台です。
- **釣り・図鑑・セーブ**は、これから作り直す**本編ゲームの機能**。
  旧プロトに実装があり、**設計・データ・手ざわりの知見は引き継ぎ資産**として残します。
- **旧 320×180 のゲーム**（いまの `npm run dev` で開くタイトル→部屋→ベランダ→釣り）は **作り直しで不要**。削除予定です。

## すぐ動かす（歩行サンドボックス）

```bash
npm run dev
```

ブラウザで **`http://localhost:5173/sandbox.html`** を開く（末尾が `/sandbox.html`）。
画像を置いていなくても、仮のキャラ（青い人形）と仮の背景（市松模様）で動きます。

ステータスの読み方： ✅ 実装済み ／ 🟡 一部・仮実装 ／ ⬜ これから

## 用語ミニ辞典（非エンジニア向け）

| 言葉 | やさしい意味 |
| --- | --- |
| マス目（タイル） | 画面を 48ドットごとの方眼にしたもの。歩行・壁・イベントはこの方眼に揃える |
| サンドボックス | 本番とは別の「練習場」。気軽に試せる画面のこと |
| ナインスライス | 枠の絵を「角は固定・辺と中央だけ伸ばす」技。文の長さで枠の角が崩れない |
| localStorage（ローカル保存） | ブラウザの中に自動で残る保存場所。リロードしても消えない |
| エディタ | ゲーム画面の中で、壁やイベントをマウスで作る編集モード |
| トリガー（きっかけ） | イベントが始まる条件。「調べる」（決定ボタン）か「踏む」（乗ると自動） |
