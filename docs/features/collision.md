# 当たり判定（壁）

> ステータス: ✅ 実装済み ／ 場所: 歩行サンドボックス（`/sandbox.html`） ／ [← 目次へ](../README.md)

## これは何？

キャラが**通れない場所（壁）**を作る仕組みです。壁は四角の集まりで、ゲーム画面の中で
**マウスで描いて・動かして・消す**ことができます（当たり判定エディタ）。描いた壁は
48ドットのマス目に自動で揃います。

## 実装済み

### 当たり判定エディタ（C キー）

| 操作 | できること |
| --- | --- |
| C | エディタの ON / OFF（イベント配置(V)とは同時に開けない） |
| マウスでドラッグ | 新しい壁の四角を描く（クリックだけなら1マス分） |
| 四角をドラッグ | その壁を動かす（マスの端に揃う） |
| X / Delete / Backspace | 選択中の壁を消す |
| R | 設定ファイルの内容に戻す |
| E | 設定ファイルに貼れる形でコピー（コンソール＋クリップボード） |
| H | 壁の赤い四角と説明文の表示／非表示（**本番と同じ見た目**を確認。壁の効きはそのまま） |

- 編集中は薄い方眼（48ドット刻み）を表示。**選択中=黄金色 / 非選択=赤 / 新規ドラッグ=緑**。
- スタート位置には青い丸＋矢印の印が出ます。

### データの形

- `collisionRects` … `[{ x, y, width, height }, ...]` の配列。
- `x, y` は四角の左上角で、マスの境目（0, 48, 96…）に揃う。
- マウス操作の値は自動でマス目に丸められます（`tileEdge` / `tileRect`）。

### 保存

- ブラウザに自動保存：キーは `tsurigee:sandbox:collision:v2:{マップID}`（**マップごとに別保存**）。
- 旧バージョン（`...:v1`、1マップ時代）は初回だけ自動で引き継ぎ。
- 確実に残したいときは **E でコピー → `src/data/walkSandbox.ts` の `collisionRects` に貼り付け**（貼り付けはこちらでやります）。

## 検討したい

- **判定範囲（すり抜け感）**：足元1マスから2px内側で判定（`inset=2`）。隣マスと辺が接しても通れるようにする工夫だが、壁の引き方によっては違和感が出ることも。
- **デバッグ機能の過不足**：H（見た目確認）と歩いての確認はあるが、他に欲しいチェック機能がないか。
