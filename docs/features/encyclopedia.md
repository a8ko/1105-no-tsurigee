# 図鑑

> ステータス: 🟡 新方向は簡易実装あり（ロケット経由のテキスト表示）／旧プロトに本格実装あり ／ [← 目次へ](../README.md)

## これは何？

釣った収集物を集めて眺める**図鑑**です。共通コンセプトの1つ（図鑑要素がある）。
新方向（1280×720）では、ベランダのロケットを調べると簡易的なテキスト形式で見られる
（下記）。グリッド表示や並び替えなど、旧プロトの**並び替え・未発見隠し**のロジックは
まだ引き継いでいない。

> どの魚が釣れるかを決める「抽選」は、釣りの瞬間に起きる仕組みなので[釣りゲーム](fishing.md)側にまとめています（図鑑は釣った結果を眺める場所）。

## 新方向の実装（簡易版）

ベランダに置いたロケットを調べ、「図鑑を見る」を選ぶと表示される。
`STAGE_1.items` を番号順に列挙し、発見済みは名前＋フレーバー、未発見は「？？？」、
進み具合（n/5）も表示する、テキストのみの一覧
（[tuning-log take24](../tuning-log.md#take24--ハムの緩和を5回目までは変化なし6回目から1回ごとに変更ロケットに図鑑閲覧を追加2026-07-16) 参照）。

発見済みアイテムは `localStorage` に保存され（`markItemCaught`/`getCaughtItems`）、
釣りシーンとベランダのシーンをまたいでも読める。並び替え・グリッド表示・詳細画面など、
旧プロトの機能はまだ無い。

## 実装状況（＝引き継ぐ資産）

以下は**旧プロトで動いている内容**（まだ新方向には引き継いでいない）。

### 図鑑UI（`EncyclopediaScene`）

- グリッド表示（5列×可変行）。未発見は「**???**」で隠す。
- 操作：矢印キーで移動、スペースで詳細、E で並び替え、Q で終了。
- 詳細表示は `CatchableDetailView`（[ダイアログ・UI](dialog-ui.md)）を釣果画面と共用。

### 並び替え（`Encyclopedia.ts`）

1. **図鑑番号順**（`encyclopediaNumber` 昇順）
2. **名前順**（発見済みを先に、未発見は番号順。日本語ロケール対応）
3. **レア度順**（`rarity` 降順、同値は番号順）
