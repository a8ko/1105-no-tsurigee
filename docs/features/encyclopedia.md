# 図鑑

> ステータス: ⬜ 新方向では未着手（資産あり）／旧プロトに実装あり ／ [← 目次へ](../README.md)

## これは何？

釣った収集物を集めて眺める**図鑑**です。共通コンセプトの1つ（図鑑要素がある）。
新方向（1280×720）ではこれから作り直しますが、**並び替え・未発見隠し**のロジックを
旧プロトから引き継げます。

> どの魚が釣れるかを決める「抽選」は、釣りの瞬間に起きる仕組みなので[釣りゲーム](fishing.md)側にまとめています（図鑑は釣った結果を眺める場所）。

## 実装状況（＝引き継ぐ資産）

新方向ではまだ作っていません。以下は**旧プロトで動いている内容**です。

### 図鑑UI（`EncyclopediaScene`）

- グリッド表示（5列×可変行）。未発見は「**???**」で隠す。
- 操作：矢印キーで移動、スペースで詳細、E で並び替え、Q で終了。
- 詳細表示は `CatchableDetailView`（[ダイアログ・UI](dialog-ui.md)）を釣果画面と共用。

### 並び替え（`Encyclopedia.ts`）

1. **図鑑番号順**（`encyclopediaNumber` 昇順）
2. **名前順**（発見済みを先に、未発見は番号順。日本語ロケール対応）
3. **レア度順**（`rarity` 降順、同値は番号順）
