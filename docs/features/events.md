# イベント

> ステータス: 🟡 配置エディタ＋会話/選択肢は実装済み／場所移動・釣り開始は未実装 ／ 場所: 歩行サンドボックス（`/sandbox.html`） ／ [← 目次へ](../README.md)

## これは何？

RPGツクールMZのように、**マップ上の好きな場所に「イベント地点」を置く**仕組みです。
位置はマウスで指定し、**中身（何が起きるか）は言葉でClaudeに伝えると実装**する、という分担で進めます。

イベントには「きっかけ（トリガー）」が2種類あります。

- 🟡 **調べる（examine）** … 地点の前で決定ボタン（スペース）を押すと発動（会話・看板・宝箱など）
- 🔵 **踏む（step）** … 地点に乗ると自動で発動（ワープ・トラップ・イベント開始など）

## 実装済み

### イベント配置エディタ（V キー）

| 操作 | できること |
| --- | --- |
| V | 配置モードの ON / OFF（当たり判定(C)とは同時に開けない） |
| クリック | その場所にイベント地点を置く（`①②③…` と番号が付く。マス中心に揃う） |
| 地点をドラッグ | 位置を動かす |
| T | 選んでいる地点の**きっかけ**を切り替え（調べる🟡 ⇄ 踏む🔵） |
| X / Delete / Backspace | 選択中の地点を消す |
| R | 設定ファイルの内容に戻す（Claudeが書いた中身はこれで反映） |
| E | 番号・座標・きっかけをコピー（Claudeに渡す） |

### イベント地点のデータの形

```ts
EventMarker = {
  x, y,                 // 置き場所（マス中心）
  trigger: "examine" | "step",   // きっかけ
  message?,             // 会話：1つのメッセージ
  prompt?, choices?,    // 選択肢：質問文＋選択肢（選ぶと reply を出す）
}
```

### いまの動き方（仮の中身）

| きっかけ | 動き |
| --- | --- |
| 🔵 踏む | 地点に乗ると自動でメッセージ。乗り続けても再発動しない（重複防止） |
| 🟡 調べる | 正面1マス（または足元）に地点があれば、スペースで発動 |
| 選択肢つき | ↑↓で選び、スペースで決定。選んだ項目に返事(`reply`)があれば追加表示 |

- メッセージ・選択肢は **WalkSandboxScene 内の独自実装**（`openMessage` / `openChoice` / `drawChoice`）。
  旧UIの `DialogBox` とは別物です（[ダイアログ・UI](dialog-ui.md) 参照）。
- 反応する距離：踏む=半径24px、調べる=正面1マス（距離40px以内、最も近い1つ）。

### 保存

- ブラウザ自動保存：`tsurigee:sandbox:events:v2:{マップID}`（マップごと）。配置・移動・削除のたびに保存。
- **中身を反映する手順**：Claudeが `walkSandbox.ts` に文章や選択肢を書く → ブラウザで **V → R** を押すと設定ファイルの内容に更新されます。

### イベントの作り方（流れ）

1. `V` で配置モードに入り、クリックで地点を置く
2. 各地点を選んで `T` できっかけ（調べる／踏む）を決める
3. `E` でコピーして Claude に渡す
4. 「①は猫がいて話しかけると鳴く」「③に乗ると別の部屋へワープ」のように**各番号の中身を言葉で伝える**
5. Claudeが中身を実装 → ブラウザで `V → R` で反映

## 検討したい

- **「場所移動」「釣り開始」の作り方**：`EventMarker` に種別フィールド（例 `action: "message" | "choice" | "teleport" | "startFishing"`）を持たせて分岐するか。
- **シンプル版 → コマンド型へ**：今は「1イベント＝1種類（会話か選択肢）」。将来「会話→選択肢→移動…」と動作を並べる**コマンド配列型**へ育てるか。要件整理に合わせて粒度を判断。
- **釣りへ行って戻る流れ**：釣りシーンへ移ったあと、戻り先（マップ・足元位置）をどこに保存するか（[セーブ](save.md)と関連）。
- **数値入力フォーム**：マウス配置だけでなく座標を数値で直接指定したいか。
