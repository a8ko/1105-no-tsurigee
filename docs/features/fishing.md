# 釣りゲーム

> ステータス: ⬜ 新方向では未着手（資産あり）／旧プロトで手ざわり完成 ／ [← 目次へ](../README.md)

## これは何？

このゲームの核になる**釣りのミニゲーム**です。共通コンセプトの1つ（釣りゲームである）。
新方向（1280×720）ではこれから作り直しますが、**旧プロトで手ざわりまで作り込んだ資産**があり、
設計・数値・知見をそのまま引き継ぎます。

> 手ざわりの調整履歴は [`tuning-log.md`](../tuning-log.md) に全テイク残っています（ゲーム性を変えたら必ず追記）。

## 実装状況（＝引き継ぐ資産）

新方向ではまだUIを作っていません。以下は**旧プロトで完成している内容**で、再構築の土台になります。

### 釣りの流れ（take2 で完成）

```
投入 →[2500–5000ms の「間」]→ ピクン0–3回＋沈み込み
   → フッキング(猶予は難易度依存) → メーター(必要成功数ぶん) → 釣果
```

- **早合わせ失敗ペナルティ**：待機中にスペースを押すと「あわてた！」で仕切り直し。
- **押しっぱなし引き継ぎ**：フッキング→メーターでスペースを押したまま繋がる（一体感）。

### メーター（`GaugeMeterGame`）

- スペースを押し続けるとゲージが左→右へ伸び、**離した位置**で判定。
- 速度 `FILL_MS = 2000ms`。判定ゾーン：Perfect `[.33,.67)` / Good `[.13,.33)`＋`[.67,.87)` / Miss 両端（やさしめ）。
- **差し替え可能設計**：`MeterGame` インターフェース（`start(): Promise<'perfect'|'good'|'miss'>`）＋ `createMeterGame` ファクトリ。釣り本体を変えずにミニゲームだけ別実装に差し替えられる。

### 難易度（`difficulty.ts`・原則変更しない）

| 難易度 | フッキング猶予 | メーター必要成功数 | Good可否 |
| --- | --- | --- | --- |
| EASY | 600ms | 1回 | 可 |
| NORMAL | 500ms | 2回 | 可 |
| HARD | 350ms | 4回 | 不可 |
| LEGEND | 250ms | 8回 | 不可 |

### 収集物データ（`catchables.ts`）

- 全 **14種**。各データ＝ `id` / `encyclopediaNumber` / `name` / `description` / `rarity(1–5)` / `difficulty` / `imageKey`。
- レア度分布：1（4種EASY）/ 2（3種NORMAL）/ 3（2種）/ 4（2種HARD）/ 5（3種LEGEND）。
- レア度（`rarity`）と難易度（`difficulty`）は連動：**レア度が高い魚ほど出にくく、かつ釣るのも難しい**。

### 抽選（`Catalog.ts`）＝どの魚が釣れるか

釣りをした瞬間に「どの収集物が釣れるか」をランダムで決める仕組み。レア度による出現確率の重み付けを担う。

- `Catalog.roll()`：重み `= (最大レア度 + 1 - rarity)²`。**レア度が高いほど二次関数的に出にくい**。
  - 例（最大レア度5のとき）：レア度1＝重み25 ／ レア度3＝重み9 ／ レア度5＝重み1（レア度1はレア度5の25倍出やすい）。
- 乱数は差し替え可能（テスト用に引数で渡せる）。
- ※ 現状この重み付けは**釣りの状態遷移にはまだ未接続**。新方向で出現リストへ繋ぐのが課題（下記TODO）。

### 状態遷移（`FishingScene`）

- 5フェーズ（watch / hookWindow / hit / transition / ended）で制御。猶予切れで魚が逃げる。
- 釣り上げ時に図鑑登録・発見フラグ・ローカル保存を呼ぶ（[図鑑](encyclopedia.md) / [セーブ](save.md)）。

## 検討したい

- **新方向の高解像度UI**：浮き・竿・ピクン演出・メーターを1280×720でどう見せるか。
- **メーターの代替案**：ファクトリ設計のおかげで差し替え可能。クリック式など次の候補を作るか。
- **rarity の出現確率反映**：難易度別の「釣りやすさ」をどう表現するか（新方向の重要バランス）。
- **マップごとの釣り場**：複数マップ各地に釣りポイントを置き、場所ごとに出現リストを変えるか（[マップ管理](maps.md)）。
- **ゲーム内チューニングエディタ**：パラメータを画面上で試せる仕組みが要るか。
