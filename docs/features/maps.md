# マップ管理（複数マップ）

> ステータス: 🟡 複数マップのデータ構造はあり（中身は今1枚）／切替UI・マップ間移動は未実装 ／ [← 目次へ](../README.md)

## これは何？

「ベランダ」「部屋の中」のような**複数のマップを持ち、行き来できる**ようにする仕組みです。
RPGツクールMZのように、各マップは「背景＋壁＋スタート位置＋イベント」をひとまとめにした箱として扱います。

> 共通コンセプトの1つ（複数マップがある）。本編の作り直しでも引き継ぎます。

## 実装済み

### 複数マップを持てるデータ構造

- `SANDBOX.maps` … マップの配列 `MapData[]`。
- 各 `MapData` = `id`（プログラム用ID）＋ `name`（表示名）＋ `background` ＋ `spawn`（スタート位置）＋ `collisionRects`（壁）＋ `eventMarkers`（イベント）。
- 現在は **1枚だけ**（`id="veranda"`）。`findMap(project, id)` で探し、`currentMap` で現在のマップを参照。

### マップごとに分けて保存

- 壁・スタート・イベントの保存キーに**マップIDを付ける**ので、編集が他マップに混ざりません。
  - 壁：`tsurigee:sandbox:collision:v2:{マップID}`
  - スタート：`tsurigee:sandbox:spawn:v2:{マップID}`
  - イベント：`tsurigee:sandbox:events:v2:{マップID}`

### 設計メモ（合意済みのゴール）

- ゴールは **ゲーム内のマウス操作で作れる**ツクールMZ風エディタ。
- データは複数マップ前提（マップ＝背景＋壁＋スタート＋イベント）。
- 進め方は段階的（下のTODO参照）。一気に作らず「動いて見える」状態を確認しながら。
