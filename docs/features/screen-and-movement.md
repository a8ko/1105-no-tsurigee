# 画面と移動

> ステータス: ✅ 実装済み ／ 場所: 歩行サンドボックス（`/sandbox.html`） ／ [← 目次へ](../README.md)

## これは何？

新方向（1280×720）の**いちばん土台**になる部分です。画面の大きさ、方眼（マス目）の考え方、
キャラの歩き方・向き・歩行アニメ、そして「次に開いたときどこから始まるか（スタート位置）」をまとめています。

操作はキーボードのみ。まずここを開いて、WASD か矢印キーで歩いてみてください。

## 実装済み

| 内容 | 具体的に |
| --- | --- |
| 画面解像度 | **1280×720** 固定。Phaser の `FIT` で、ウィンドウに合わせて等比で拡大縮小 |
| マス目（タイル） | **48ドット**単位の方眼。キャラの足元はマスの中心（24, 72, 120…）に揃う |
| 歩行モデル | RPGツクール風の**マス目移動**。1歩 = 48ドット、**320ms** で1歩。斜め移動なし（左右優先） |
| 向き | 4方向（down=0行 / left=1行 / right=2行 / up=3行） |
| 歩行アニメ | 各向き 列 `0,1,2,1` の4コマを往復（`fps=6`）。止まると `idleColumn=1` の絵 |
| 表示サイズ | `displayScale=1.0`（原寸。MZ標準シートなら1コマ384px） |
| スタート位置(P) | **P キー**で今いる場所をスタート位置に保存。マス中心に揃え、ブラウザに自動保存 |

### 操作キー（移動まわり）

| キー | できること |
| --- | --- |
| WASD / 矢印キー | 歩く（向きとアニメが変わる） |
| P | いまいる場所を「スタート位置」にする（次に開くとそこから始まる） |

> 当たり判定エディタ(C)・イベント配置(V)・素材まわりのキーは、それぞれ
> [当たり判定](collision.md) / [イベント](events.md) / [素材システム](assets.md) のページに分けて書いています。

### 画像の差し替え（手作業）

| 種類 | 置くファイル |
| --- | --- |
| 歩行キャラ | `public/assets/character.png`（仮素材は自動生成の青い人形） |
| 背景 | `public/assets/background.png`（仮素材は市松模様） |

同じ名前で上書きしてリロードすれば差し替わります。コマ数やサイズが変わる場合は
`src/data/walkSandbox.ts` の数値（`frameWidth/frameHeight/columns/rows/directions`）を合わせます。
迷ったら絵を見せてください。正しい数値をこちらで割り出します。

## 検討したい

- **歩行アニメの滑らかさ**：今は `fps=6`・3コマ往復（MZ標準）。「もっと滑らか／もっとカクカク」の好みがあれば数値で調整。
  本当に滑らかにするにはコマ数を増やした絵が必要。
- **すり抜け感**：当たり判定は足元1マス（48ドット）から2px内側で判定（`inset=2`）。壁の引き方次第で「すり抜けた」と感じることがあり、調整余地あり。
- **スタート位置の保存範囲**：今はマップ(`mapId`)ごとに保存。複数マップ時代に古いデータをどう扱うか（[セーブ](save.md)とも関連）。
