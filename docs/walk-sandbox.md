# 歩行キャラ・サンドボックス 使い方ガイド

1280×720 の新しい画面で、歩行キャラを歩かせ・背景を表示し・当たり判定（壁）を作るための練習場です。
**既存の釣りゲーム（320×180）とは別物**で、お互いに影響しません。

---

## 1. 開き方

ターミナルで開発サーバを起動して、ブラウザで sandbox のページを開きます。

```bash
npm run dev
```

ブラウザで次を開く（末尾が `/sandbox.html`）：

```
http://localhost:5173/sandbox.html
```

> 画像をまだ置いていなくても動きます。仮のキャラ（青い人形）と仮の背景（市松模様）が出ます。

---

## 2. 操作

| キー | できること |
| --- | --- |
| WASD / 矢印キー | 歩く（向きとアニメが変わる） |
| P | いまいる場所を「スタート位置」にする（次に開いたときそこから始まる） |
| C | 当たり判定エディタの ON / OFF |
| H | 当たり判定（赤い四角）と説明文の表示／非表示。**非表示にすると本番と同じ見た目**になる（壁の効き目はそのまま） |

> `H` を押すと赤い四角と左上の説明がまとめて消え、お客さんが遊ぶ本番の見た目を確認できます。もう一度 `H` で戻ります（編集モード中は描けるよう必ず表示）。

### スタート位置の変え方

1. スタートさせたい場所まで**歩いて移動**する（壁の中＝当たり判定で囲った中にも入れます）
2. **`P` キー**を押す → その場所がスタート位置として保存される（ブラウザに自動保存）
3. 次にページを開くと、その場所から始まります

> 編集モード（C）中は、スタート位置に**青い丸＋旗の印**が表示されます。
> 確実にファイルへ残したいときは、編集モードで `E` を押すと「スタート位置＋当たり判定」がまとめてコピーされるので、私に渡してください。

### 当たり判定エディタ（C を押している間）

| 操作 | できること |
| --- | --- |
| マウスでドラッグ | 新しい壁の四角を描く |
| 四角をドラッグ | その四角を動かす |
| X または Delete | 選択中の四角を消す |
| R | 設定ファイルの内容に戻す |
| E | 設定ファイルに貼れる形でコピー（後述） |

描いた四角は**ブラウザに自動保存**され、リロードしても消えません。

## 3. 画像を入れる・差し替える（あなたが手でやる作業）

画像は **`public/` フォルダ** に置きます。

| 種類 | 置くファイル名（現在の設定） |
| --- | --- |
| 歩行キャラ | `public/character.png` |
| 背景 | `public/background.png` |

- ファイルを**同じ名前で上書き**すれば、ブラウザを更新（リロード）するだけで差し替わります。
- 別のファイル名にしたいときは、設定ファイル（次項）のパスを書き換えます。

---

## 4. 設定ファイル `src/data/walkSandbox.ts`

キャラのコマ数・サイズ・速さ・背景・当たり判定は、すべてこの 1 ファイルにまとまっています。
日本語コメント付きで、`★` が付いた行が「よく変える場所」です。

### よく変える項目

| 項目 | 意味 |
| --- | --- |
| `character.path` | 歩行キャラ画像のパス |
| `character.frameWidth / frameHeight` | 1コマ（1枚の絵）のサイズ |
| `character.columns / rows` | シート全体が何列・何行か |
| `character.directions` | どの行がどの向きか＋歩行で使う列の順番 |
| `character.fps` | 歩行アニメの速さ |
| `character.displayScale` | 画面に表示する大きさ（拡大率。1.0＝原寸） |
| `character.stepTile` | 1歩で進む距離（マス目移動のマスの大きさ） |
| `character.stepMs` | 1歩にかける時間（小さいほどキビキビ） |
| `background.path` | 背景画像のパス |
| `collisionRects` | 当たり判定（壁）の四角の一覧 |

### RPGツクールMZ の画像について

1152×1536 のシートは、**中身によってコマのサイズが変わります**：

- **1キャラだけ**（横3列×縦4行）→ 1コマ **384×384**（初期設定はこちら）
- **複数キャラが並んでいる** → 1コマ **96×192** など

置いた画像を見せてもらえれば、正しい数値をこちらでお伝えします。

### 「もっと滑らかに動かしたい」とき

MZ は 1方向 **3コマ**しかないので、それ以上は根本的には滑らかになりません
（今は `[1,0,1,2]` と往復させて、少しでも滑らかに見せています）。
本当にヌルヌル動かすには、**コマ数を増やした絵**を用意し、`columns` と `directions` の `frames` を増やします。
例）1方向6コマなら `columns: 6`、`frames: [0,1,2,3,4,5]`。

## 5. 当たり判定を「保存」する手順

エディタで描いた四角はブラウザに自動保存されますが、**設定ファイルに書き込むと確実に残ります**：

1. エディタ（C）で壁の四角を描く
2. `E` を押す → クリップボードにコピーされる（コンソールにも出力）
3. `src/data/walkSandbox.ts` の `collisionRects: []` の `[]` の中に貼り付けて保存

> 貼り付け作業は私（Claude）に「これを貼って」と渡してくれれば、こちらで設定ファイルに入れます。
